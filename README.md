基于脑电信号的运动想象分类系统，实现从原始EDF数据到运动想象任务解码的完整流程。  
  
本项目实现了一套完整的脑机接口（BCI）数据处理流程，用于解码三类运动想象脑电信号。系统支持多种机器学习与深度学习模型，包括 SVM、随机森林和 CNN（EEGNet），并提供了模块化的特征提取与模型评估功能。  

特点：  
①完整的预处理流程：基于 MNE 实现 EDF 数据加载、通道选择、信号归一化  
②多种特征提取方法：CSP 空域滤波、频带能量、时域统计特征  
③多模型支持：SVM、随机森林、EEGNet  
④模块化设计：配置、数据加载、预处理、特征提取、训练、评估各模块解耦  
⑤可复现实验：支持多被试数据加载、交叉验证、模型保存与加载
